# Security reporting

Please do not publish credentials, personal data, or unpatched vulnerability details in a public issue.

For a sensitive report, use GitHub's private vulnerability reporting for this repository when it is available. Include the affected component, steps to reproduce in a controlled environment, and the potential impact. Do not include real member records or production credentials.

This repository is a software source release, not a security certification of every deployment. Operators must configure secrets outside source control, restrict administrative access, and apply updates to their own deployments.
